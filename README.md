# 수산그룹 월간 보안보고 웹 서비스

## 진행 순서 (요청하신 순서대로)
1. ✅ **전체 템플릿 디자인** — `client/` (현재 단계, 목업 데이터로 화면 완성)
2. ⏳ **관리자 입력폼 + 백엔드/DB** — `server/` (다음 단계에서 구축)
3. ⏳ **테스트 및 배포**

## 전체 아키텍처 (계획)
```
[관리자 입력폼] → [백엔드 API + DB] → [담당자 웹 조회 / PDF 다운로드]
   (React)         (Node/Express        (React, 동일 코드베이스
                    + SQLite)             company 파라미터로 필터링)
```

- **Frontend**: React + Vite (`client/`)
- **Backend (2단계)**: Node.js + Express + SQLite(초기)/PostgreSQL(운영 전환 가능), 월별 보고서 데이터 CRUD API
- **PDF 다운로드 (2단계)**: 서버에서 Puppeteer로 웹 화면과 동일한 레이아웃을 그대로 PDF 변환 (웹=PDF 싱크 보장)
- **접근 제어**: 현재는 요청하신 대로 인증 없이 "회사 선택" 방식. 이후 로그인이 필요해지면 세션/회사코드 매핑만 추가하면 되도록 `?company=코드` 구조로 미리 설계함

## 데이터 구조 원칙
- **공통 데이터** (5개사 전체 동일): 개요, 계열사별 현황 테이블, 주요 보안 이슈사항, 보안 진단 현황, 보안 공지, 모의훈련 결과 등
- **회사별 비공개 데이터**: "보안 성적표"(종합등급/구축률/체크리스트/경영진 제언)만 회사코드로 필터링되어 본인 회사 것만 노출

> ⚠️ 참고: 원본 문서의 "악성메일 모의훈련 명단(이름/직급/이메일)"은 개인정보이므로, 실제 서비스에서는 보안 성적표처럼 회사별로 접근을 제한하는 것을 권장합니다. 우선 요청하신 대로 공통 섹션에 포함해 두었으니, 검토 후 알려주시면 다음 단계에서 접근 범위를 조정하겠습니다.

## 실행 방법
```bash
cd client
npm install
npm run dev
```
